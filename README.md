🚀 Hakiman Fullstack
A high-performance portfolio system built with a focus on modern UI/UX and robust backend integration. This project features a public-facing site and a secured admin dashboard, utilizing React for the frontend and Supabase for the entire backend ecosystem.

Live Demo: 

🛠️ Tech Stack
Frontend: ReactJS (Vite) & Tailwind CSS

Backend: Supabase (PostgreSQL, Auth, Storage)

Animations: Framer Motion & AOS (Animate On Scroll)

Components: Material UI, Lucide React, & SweetAlert2

Deployment: Vercel / Netlify

🏗️ Database Architecture
This project implements Row Level Security (RLS) to ensure data is protected while remaining accessible to the public where intended.

SQL Setup (Supabase)
SQL
-- Project management table
CREATE TABLE public.projects (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title text NOT NULL,
  description text,
  img text,
  link text,
  github text,
  tech_stack jsonb,
  is_published boolean DEFAULT true,
  order_index int DEFAULT 0,
  created_at timestamptz DEFAULT now()
);

-- User profiles for Admin RBAC
CREATE TABLE public.profiles (
  id uuid PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  username text UNIQUE NOT NULL,
  role text NOT NULL CHECK (role IN ('admin', 'user')),
  created_at timestamptz DEFAULT now()
);
🚀 Installation & Usage
1. Clone & Dependencies
Bash
git clone 
cd Portofolio_V5
npm install
2. Environment Variables
Create a .env file in the root directory:

Cuplikan kode
VITE_SUPABASE_URL=your_project_url
VITE_SUPABASE_ANON_KEY=your_anon_key
3. Run Development
Bash
npm run dev
🔑 Key Features
Public Interface: Dynamic project gallery, certificate showcase, and real-time comment system.

Admin Dashboard: Full CRUD operations for projects and certificates, and management of user comments (Pin/Delete).

Storage Integration: Automatic image handling via Supabase Buckets.

Real-time Updates: Instant UI feedback for new comments using Supabase Realtime.
